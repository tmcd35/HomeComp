# September 1977 Launch

The September 1977 launch is the first public HomeComp release wave.

It introduces the HC-77B and establishes the starting point for HomeComp Ecosystem Era 1.

![HC-77B September 1977 product sheet](https://github.com/tmcd35/HomeComp/raw/master/documents/advertising/HC-77B%20Product%20Sheet.png)

*September 1977 HC-77B launch product sheet.*

## Release Contents

| Category | Released Material |
|---|---|
| System | HC-77B base system |
| Firmware | HC-77B boot/monitor ROM |
| Emulator | HC-77B emulator builds for Windows, macOS, and Linux |
| Documentation | HC-77B user and technical documentation |
| Extensions | TTY Interface, Video Display Controller, Keyboard |
| Media support | Cassette handling and blank tape creation |
| Tools | Initial public development/support tools where included |

## Standalone Launch Extensions

The September 1977 launch includes three standalone extension products available in the repository's `extensions/` section.

| Extension | Role |
|---|---|
| TTY Interface | Adds teletype-style character input/output support |
| Video Display Controller | Adds video display support for the HC-77B |
| Keyboard | Adds keyboard input support for expanded use |

These are treated as public launch products rather than built-in assumptions of the base HC-77B package.

## Release Role

This release establishes the public baseline for HomeComp.

It defines:

- the first released HomeComp machine
- the initial emulator environment
- the first standalone extension products
- the September 1977 launch context
- the first public documentation set
- the starting point for later ecosystem releases

## HC-77B Position

The HC-77B is the first HomeComp system: a 1977 front-panel MOS 6502 microcomputer designed as a serious expandable launch machine.

For the machine specification and memory map, see [HC-77B Technical Overview](HC-77B-Technical-Overview).

For modern emulator usage, see [Emulator User Manual](Emulator-User-Manual).

For company background and historical context, see [HomeComp History & Lore](HomeComp-History-and-Lore).

## Release Notes

The September 1977 release is intentionally focused.

It presents the HC-77B, its emulator environment, three launch extension products, and its supporting launch documentation as the first public slice of the HomeComp ecosystem.
