# Machine Technical Reference

This section provides high-level technical reference material for publicly released HomeComp machines.

It is intended to give users and developers a clear overview of each released machine's hardware model, memory map, expansion position, supported configurations, and emulator status. It does not replace the full technical specification documents or machine manuals included with releases.

## Released Machines

| Machine | Launch Context | CPU | Status |
|---|---|---|---|
| HC-77B | September 1977 launch system | MOS 6502 | Released |

## Current Pages

## Scope

Each released machine page may include:

- release context
- CPU and clock
- RAM and ROM configuration
- display and input model
- storage support
- expansion model
- high-level memory map
- emulator support status
- links or references to relevant released documents

Detailed fictional machine operation belongs in the included machine manuals. Modern emulator usage belongs in the [Emulator User Manual](Emulator-User-Manual).

## Current Release Focus

The current public technical focus is the September 1977 HC-77B launch.

Later HomeComp machines and later HC-77B ecosystem additions will be documented as they are publicly released.
