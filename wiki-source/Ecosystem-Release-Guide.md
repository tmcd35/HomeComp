# Ecosystem Release Guide

This section records the public HomeComp ecosystem as it is released.

It is organised by release wave. Each page describes what exists in that public release and how the pieces fit together.

## Purpose

The Ecosystem Release Guide is not a technical reference and not a machine manual.

It answers:

- which release wave this is
- which public artefacts belong to it
- which system or ecosystem era it introduces
- where to go for emulator usage, machine details, lore, or API documentation

## Release Categories

A release wave may include:

| Category | Examples |
|---|---|
| Systems | Machines and configurations |
| Firmware | ROMs and built-in machine software |
| Software | Programs, cassette images, disk images, languages |
| Hardware | Peripherals, expansions, and add-ons |
| Documentation | Manuals, technical notes, product sheets, books |
| Adverts | Period-style promotional material |
| Tools | Modern support tools and project utilities |
| Examples | Third-party extensions or peripheral examples |
