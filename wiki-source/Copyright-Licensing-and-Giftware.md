# Copyright, Licensing and Giftware

HomeComp is not an open-source project.

The public repository and wiki exist to provide release packages, documentation, fictional product material, selected source examples, developer-facing API material, and supporting artefacts for the HomeComp project.

Public HomeComp releases are made available in the public domain as giftware. They may be downloaded, used, copied, shared, and archived freely. Optional donations may be accepted through itch.io and Ko-fi, but payment is not required.

## Giftware

Public HomeComp emulator releases are made available as giftware.

This means they may be downloaded and used freely. Donations are optional and may be accepted through itch.io and Ko-fi, but payment is not required to use the public releases.

## Closed Source Position

The main emulator source code is not currently published in full.

Public releases may include selected source code, listings, examples, SDK files, and development material where useful. The presence of those files does not imply that the full emulator codebase is open source.

## Public-Domain-Style Material

Unless stated otherwise, public documentation, adverts, screenshots, fictional product material, and other non-source release artefacts are made available under a public-domain-style dedication where possible.

This is intended to allow the project material to be read, shared, archived, discussed, and preserved freely.

## Published Source Code and Listings

Where source code is published, including CPU cores, monitor assembly listings, BASIC listings, example programs, SDK material, and third-party extension examples, it is offered under a copyleft licence stated with that material.

Examples may include:

- published CPU core source
- monitor ROM assembly listings
- BASIC program listings
- example cassette or ROM programs
- extension SDK examples
- third-party peripheral examples

Always check the licence notice included with the specific source file or package.
