# September 1978 — HC-PILOT and 8K ROM BASIC

> **Status: planned next release wave.** This page is a public release marker, not final language documentation.

The planned September 1978 release moves the HC-77B from cassette-loaded language experiments toward a more complete small home-computer environment.

## Release Direction

The two products serve different uses.

**HC ROM BASIC** is planned as the resident BASIC environment for an HC-77B fitted with the 8K ROM BASIC board. It will make installed working RAM available primarily to the user rather than consuming it with a cassette-loaded interpreter.

**HC-PILOT** is planned as a small cassette-loaded language for structured instructional and text-oriented programs. Its initial command set will remain deliberately compact and appropriate to the HC-77B's memory limits.

## Documentation Status

Detailed command syntax, memory maps, media layout, hardware requirements, and compatibility notes will be published with the release. They are intentionally not frozen by this roadmap page.
