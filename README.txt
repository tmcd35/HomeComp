HomeComp Computer Family Public Files

This Internet Archive item is the public file bucket for the HomeComp Computer Family project, an alternate-history retrocomputing project centred on the fictional HomeComp range of microcomputers.

It contains public emulator releases, ROM images, cassette and disk images, documentation, example adverts, screenshots, and third-party peripheral examples.

All files are original HomeComp project material unless explicitly stated otherwise.
